# GigiPlayz

This repository hosts the GitHub Pages redirect for **GigiPlayz**.

- GitHub Pages address: https://gigiplayz.github.io/
- Main website: https://gigiplayz.pages.dev/
- Organization owner: [Gigimeow](https://github.com/Gigimeow)

## How it works

The index.html page immediately forwards visitors to the main website. It uses JavaScript and an HTML refresh, with a clickable link as a fallback.

## Updating the redirect

Update the destination URLs in index.html and this README, then commit to the main branch. GitHub Pages automatically builds and publishes the update.
